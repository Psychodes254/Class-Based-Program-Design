# Class-based Program Design

## Overview

This repository contains solutions and projects completed while studying **Class-based Program Design**. The primary focus is on designing clean, maintainable software using object-oriented programming principles and functional design patterns in Java.

### Key Concepts Covered

- **Object-Oriented Core:** Interfaces, Abstract Classes, Inheritance, Polymorphism, and Object Composition
- **Data & Types:** Generic Data Structures, Immutable Data, and Recursion
- **Software Engineering Practice:** Design Recipes, Unit Testing, and Functional Abstractions

---

## Technologies Used

- **Language:** Java
- **IDE:** Eclipse
- **Testing:** Northeastern Tester Library (or JUnit)
